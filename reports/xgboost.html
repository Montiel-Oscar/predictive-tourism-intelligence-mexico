Modelo Predictivo de Turismo Internacional — México¶

XGBoost¶

Objetivo del proyecto¶

Predecir el flujo mensual de turistas extranjeros que arriban a México por aeropuerto, país de residencia y género. Los datos provienen del sistema DATATUR de la Secretaría de Turismo de México, período 2012–2025.

Algoritmo: XGBoost (Extreme Gradient Boosting)¶

A diferencia de Random Forest, que construye muchos árboles independientes y promedia sus predicciones, XGBoost construye los árboles en secuencia: cada árbol nuevo analiza dónde se equivocó el árbol anterior y aprende a corregir exactamente esos errores. Este proceso se llama gradient boosting.

La ventaja es que el modelo enfoca toda su capacidad en los casos más difíciles de predecir. La desventaja es que requiere más cuidado en su configuración para evitar que memorice el ruido de los datos de entrenamiento.

Estrategia de entrenamiento en dos fases¶

XGBoost tiene un mecanismo llamado early stopping: monitorea el error en un conjunto de validación mientras entrena y se detiene automáticamente cuando ese error deja de mejorar. Esto evita el sobreajuste sin tener que adivinar cuántos árboles son suficientes.

Para que este mecanismo sea válido, el conjunto de validación debe ser posterior en el tiempo al conjunto de entrenamiento. Si se usara datos mezclados, el modelo tendría señales del futuro y sus resultados serían artificialmente buenos.

FASE 1 — Calibración:
  Entrenamiento : 2012 – Junio 2022
  Early stopping: Julio – Diciembre 2022
  Resultado     : número óptimo de árboles (BEST_N)

FASE 2 — Modelo final:
  Entrenamiento : 2012 – 2022 completo
  Árboles       : exactamente BEST_N
  Evaluación    : 2023, 2024, 2025

Usar 2022 completo en la Fase 2 (en lugar de solo hasta junio) añade más datos de entrenamiento sin comprometer la honestidad de la evaluación, ya que ningún año de validación (2023-2025) aparece en el entrenamiento.

Umbrales de evaluación¶

Umbral Interpretación
≥ 250 turistas Actividad mínima para planificación
≥ 1,000 turistas Rutas comercialmente activas
≥ 10,000 turistas Destinos de alta demanda

3. Ingeniería de variables¶

Se construyen cinco variables adicionales que complementan los rezagos temporales del dataset base:

mes_share_aeropuerto — Estacionalidad estructural: Para cada aeropuerto, el porcentaje de su tráfico anual que llega en cada mes. Huatulco concentra el 60% de sus turistas entre enero y marzo, casi nada en verano. Cancún tiene una distribución más uniforme pero con picos en Navidad. Esta variable se calcula únicamente sobre datos hasta junio 2022 para no filtrar información del futuro hacia el entrenamiento.

log_lag1, log_rolling, log_lag12 — Rezagos logarítmicos: El modelo aprende sobre el logaritmo del target porque el flujo de turistas es muy asimétrico (entre 1 y 300,000). Tener los rezagos en la misma escala logarítmica facilita que el modelo aprenda las relaciones multiplicativas directamente.

ratio_lag1_lag12 — Crecimiento interanual: Compara el último mes con el mismo mes del año pasado. Un valor mayor a 1 indica que el turismo está creciendo.

tendencia_reciente — Momentum de corto plazo: Compara el último mes con el promedio de los tres meses anteriores. Detecta si hay una aceleración o desaceleración reciente.

df_share = df[
    (df['Ano'] < 2022) | ((df['Ano'] == 2022) & (df['MesNum'] <= 6))
].copy()
anual = (
    df_share.groupby(['Aeropuerto','Ano'])[TARGET]
    .sum().reset_index().rename(columns={TARGET: 'Total_anual'})
)
mes_a = (
    df_share.groupby(['Aeropuerto','Ano','MesNum'])[TARGET]
    .sum().reset_index().merge(anual, on=['Aeropuerto','Ano'])
)
mes_a['share'] = mes_a[TARGET] / mes_a['Total_anual'].clip(lower=1)
share_m = (
    mes_a.groupby(['Aeropuerto','MesNum'])['share']
    .mean().reset_index().rename(columns={'share': 'mes_share_aeropuerto'})
)
df = df.merge(share_m, on=['Aeropuerto','MesNum'], how='left')
df['mes_share_aeropuerto'] = df['mes_share_aeropuerto'].fillna(1/12)

# Rezagos en escala logarítmica
df['log_lag1']    = np.log1p(df['Lag_1_mes'])
df['log_rolling'] = np.log1p(df['Rolling_3m'])
df['log_lag12']   = np.log1p(df['Lag_12_meses'])

# Ratios de tendencia (acotados para evitar valores extremos)
eps = 1.0
df['ratio_lag1_lag12']   = (df['Lag_1_mes'] / (df['Lag_12_meses'] + eps)).clip(0.2, 5.0)
df['tendencia_reciente'] = (df['Lag_1_mes'] / (df['Rolling_3m']   + eps)).clip(0.2, 5.0)

if 'Años_desde_inicio' not in df.columns and 'Anos_desde_inicio' in df.columns:
    df = df.rename(columns={'Anos_desde_inicio': 'Años_desde_inicio'})

4. División temporal y definición de variables predictoras¶

Se definen los cuatro conjuntos de datos necesarios para la estrategia de dos fases.

El punto crítico es que ningún dato de 2023 en adelante aparece en ningún conjunto de entrenamiento. Los tres assert al final verifican automáticamente esta condición y detienen el notebook con un error claro si algo está mal.

A diferencia de Random Forest, XGBoost recibe el target en escala logarítmica (log1p) en la Fase 1 porque su función de pérdida estándar (error cuadrático) funciona mejor en esa escala para distribuciones asimétricas.

5. Fase 1 — Calibración con early stopping¶

El modelo entrena sobre 2012–junio 2022 y monitorea su error en julio–diciembre 2022. Cuando el RMSE en ese conjunto deja de mejorar durante 200 rondas consecutivas, el entrenamiento se detiene y se registra el número de árbol que tuvo el menor error como BEST_N.

Parámetros principales:

  • max_depth=9: profundidad máxima de cada árbol. A mayor profundidad, más capacidad de aprender pero también más riesgo de sobreajuste.
  • learning_rate=0.005: tamaño del paso en cada iteración. Un valor pequeño requiere más árboles pero produce predicciones más estables y precisas.
  • subsample=0.8 y colsample_bytree=0.8: cada árbol ve el 80% de los datos y el 80% de las variables, lo que introduce diversidad y reduce el sobreajuste.
  • reg_lambda=1.5: penalización L2 que evita que los pesos de las hojas sean demasiado grandes.

7. Evaluación con múltiples umbrales¶

La función predecir aplica la transformación inversa del logaritmo (expm1) para obtener el número de turistas en escala real.

La función evaluar calcula cinco métricas y las reporta para cada uno de los cuatro umbrales de negocio definidos al inicio. El número n entre paréntesis indica cuántos registros superan ese umbral — a medida que el umbral sube, quedan menos registros pero son los más relevantes para el negocio.

In [8]:
def predecir(X):
    """Predice en número de turistas reales (revierte la transformación log)."""
    return np.maximum(np.expm1(xgb_final.predict(X)), 0)

def evaluar(y_real, pred, nombre, umbrales=UMBRALES):
    """Calcula y reporta todas las métricas de evaluación."""
    mae    = mean_absolute_error(y_real, pred)
    rmse   = np.sqrt(mean_squared_error(y_real, pred))
    r2     = r2_score(y_real, pred)
    mape_g = np.median(np.abs((y_real - pred) / np.maximum(y_real, 1)) * 100)

    print(f"\n{'='*62}")
    print(f'  {nombre}')
    print(f"{'='*62}")
    print(f'  R²           = {r2:.4f}')
    print(f'  MAE          = {mae:>10,.1f} turistas')
    print(f'  RMSE         = {rmse:>10,.1f} turistas')
    print(f'  MAPE global  = {mape_g:.1f}%  (todos los registros, incl. segmentos pequeños)')

    mapes = {}
    for u in umbrales:
        mask   = y_real >= u
        n      = mask.sum()
        if n > 0:
            m      = np.median(np.abs((y_real[mask]-pred[mask]) / np.maximum(y_real[mask],1)) * 100)
            estado = 'DENTRO ±15%' if m <= 15 else f'a {m-15:.1f} pts del límite'
            print(f'  MAPE ≥{u:>7,} = {m:5.1f}%  (n={n:,} registros)  {estado}')
            mapes[u] = round(m, 1)
        else:
            print(f'  MAPE ≥{u:>7,} = sin registros suficientes')

    return {'r2': round(r2,4), 'mae': round(mae,1), 'rmse': round(rmse,1),
            'mape_g': round(mape_g,1), 'mapes': mapes}

8. Importancia de variables¶

XGBoost registra cuánto contribuye cada variable a reducir el error a lo largo de todos los árboles del modelo. La importancia reportada es la ganancia promedio: cuánto mejora el error de predicción cuando se usa esa variable para dividir un nodo del árbol.

Las variables de rezago dominan porque el turismo del mes pasado es el predictor más fuerte del turismo del mes siguiente. Los rezagos logarítmicos (log_lag1, log_rolling) suelen tener alta importancia porque están en la misma escala que el target.
